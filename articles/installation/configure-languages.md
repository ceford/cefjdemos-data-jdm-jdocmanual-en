The Jdocmanual **Languages** page shows a list of languages available in your Joomla installation. The publication **Status** of each language is for information only. It cannot be changed here. Go to the System / Content Languages page to change a language status. This is an example screenshot of the Languages page:

![screenshot of the jdocmanual languages page](../../../en/images/installation/configure-languages/00-languages-page.png)

Select any language that you wish to use in Jdocmanual. The default language set in the Options must always be selected. Others are optional.
